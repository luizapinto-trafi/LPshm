# Shapermint Mobile UI Kit

Mobile web surfaces (designed for 375px viewport), matching the Figma `/Organisms/Mobile` frames.

**Screens**:
1. **Home** — sticky status-ish promo, nav, hero, category preview, product row
2. **PDP** — full-width gallery, compact color/size selectors, sticky Add-to-Cart at bottom
3. **Cart** — full-screen cart (mobile doesn't use the side-drawer pattern)

**Components**: mobile top nav, hamburger drawer, hero, product row, pill selectors, sticky footer CTA.
