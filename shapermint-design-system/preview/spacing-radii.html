These are the five canonical radii used across Shapermint. Use only these tokens — any value in between (6, 10, 12px, 999px) is off-system. Tokens are defined as CSS custom properties in colors_and_type.css.

TokenValue
radius-none
0px · 0 rem
Flush edges, full-bleed imagery, section rows
radius-md
4px · 0.25 rem
Tags, small chips, thumbnail tiles, checkboxes
radius-lg
8px · 0.5 rem
★ Default — buttons, inputs, cards, size chips, modals
radius-xl
16px · 1 rem
Large cards, hero image wells, bottom sheets
radius-full
9999px
Pills, avatars, color dots, count badges
