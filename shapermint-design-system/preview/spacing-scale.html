These are the 17 canonical spacing tokens. Use only these values for padding, gap, margin and layout rhythm — anything in between is off-system. Tokens follow a 100-based numbering so scale is obvious at a glance: space-100 = 0.5 rem (8px), space-200 = 1 rem (16px), and so on. Legacy --s-* tokens are mapped onto this set for backward compatibility.
